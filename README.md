# 📊 Remote Work and Mental Health Analysis

This repository contains a research project analyzing the impact of remote work on mental health, based on a structured report and a comprehensive dataset. Visualizations were created using **Tableau**, providing interactive insights into key trends and findings.

## 📌 Objectives

* Examine the relationship between remote work and employee mental health.
* Understand how demographic, organizational, and support-related factors influence mental wellbeing.
* Use Tableau to create impactful visual dashboards based on data insights.
* Support recommendations for employers and policymakers.

## 📄 Project Description

The analysis is based on the dataset `Remote_Work_and_Mental_Health.csv`, which includes variables such as:

* Gender, Age, Marital Status
* Mental health condition history
* Remote work frequency and experience
* Employer support and mental health policy
* Comfort discussing mental health with colleagues or supervisors

## 📈 Tools Used

* **Tableau**: For all data visualizations and dashboards.
* **Microsoft Word**: For compiling reports.
* **CSV format**: For raw data processing and upload into Tableau.

## 🔍 Key Findings

* Employees working remotely with supportive employers reported better mental health.
* Many employees expressed reluctance to discuss mental health issues at work.
* Younger individuals and those without family support had higher mental health vulnerability.
* Organizations with clear mental health policies saw greater employee confidence in seeking help.

## 📊 Tableau Dashboards

The visual analysis includes:

* Mental health condition breakdown by demographics
* Remote work frequency vs. mental wellbeing
* Impact of employer support on mental health management
* Comfort levels discussing mental health in the workplace
